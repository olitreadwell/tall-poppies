# The Meetup Method — venue framework

No stars. No "best of" lists. Just signals that matter to a tall crew.

## Part A: the 8-signal scorecard

| Signal | Tag options |
| --- | --- |
| Ceiling height | 🦒 Stand Tall / 🦒 Slight Crouch / 🦒 Duck Alert |
| Table fit | 🪑 Legs Out / 🪑 Fine / 🪑 Knees Up |
| Light | ☀️ Bright / ☀️ Fine / ☀️ Cave |
| Noise level | 🤫 Chatty / 🤫 Shouty / 🤫 Ear-Splitting |
| Crowd / people | 👔 After-Work / 👖 Students / 👗 Date Night / 🧳 Tourists / 🦒 Locals Only |
| Service speed | ⚡ Instant / ⚡ Fine / ⚡ Slow / ⚡ Abandoned |
| Price (value) | 💰 Steal / 💰 Fair / 💰 Pricey / 💰 Robbery |
| Vibe | 🕯️ Cosy / 🕯️ Lively / 🕯️ Dingy / 🕯️ Dead |

## Part B: "Who's this for?" verdict

| Profile | Description |
| --- | --- |
| 🦒 The Tall Local | "You want to stand up without ducking." |
| 🍻 The Social Butterfly | "You want a table where everyone can see." |
| ☕ The Low-Key Regular | "You want a quiet spot with good light." |

## Final verdict

- 🦒 **Giraffe Approved** — perfect for all three profiles
- 👍 **Worth the Stretch** — great for 1–2 profiles, fine for the other
- 🙅 **Duck Out** — disappoints all three

## "Who would hate this?"

Every venue check closes with an honest call-out: name the 2–3 profiles
who shouldn't bother coming. This keeps Tall Poppies unfiltered instead
of another glossy "best of" list.

Use [docs/reviews/template.md](template.md) to write one; finished venue
checks go in `docs/reviews/venue-reviews/`. See
[docs/reviews/agent-workflow.md](agent-workflow.md) for the exact
find/copy/fill/commit steps.
